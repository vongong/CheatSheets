# Fastly VCL
- Fastly VCL (Varnish Configuration Language) is a domain-specific programming language used to configure and customize how requests and responses are processed on Fastly's edge cloud platform.
- Fastly's cache servers run an evolution of Varnish which diverged from the community project at version 2.1.
